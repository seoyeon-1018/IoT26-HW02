# IoT26-HW02: Button-Controlled LED

## Project Description
This project turns an LED on and off using a push button.
When the button is pressed, the LED turns on.
When the button is released, the LED turns off.

## Hardware Components
- Raspberry Pi 5
- LED
- Push button
- Resistor
- Breadboard
- Jumper wires

## Circuit Connection
- LED: GPIO 14
- Button: GPIO 4

## Source Code
The Python code uses gpiozero Button and LED classes.
The button controls the LED state.
